#                     analytic dataset from source
#
#   python -m pip install -r requirements-full.txt
#

# most platform-sensitive part of this stack. If the pinned pair fails to
# install on your platform, relax those two lines only -- they affect the SHAP
# analyses, not any performance estimate reproduced by this bundle.
